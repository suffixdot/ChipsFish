# 🐟 ChipsFish

> **The #1 Damath Engine & Interactive Web Suite**

ChipsFish is the first high-performance C++ engine and web interface designed specifically for official DepEd Damath variants (Counting, Whole Number, Fraction, Integer, Rational, Radical, Polynomial, and Thermo Sci Dama).

---

## ⚡ Quick Start

Simply run the **`start_gui.command`** script to automatically build the engine and launch the web GUI in your browser:

```bash
./start_gui.command
```

---

## ✨ Features

- **Unbeatable Engine Logic**: Evaluates deep tactical capture sequences and multi-step jump combinations.
- **Position Memory & Opening Book**: Automatically caches deep analysis (TT) to build a master opening book over time.
- **Real-Time Best Move Analysis**: Toggle "Show Best Move" to visualize recommended lines and engine evaluation live during games.
- **Full DepEd Variant Support**: Seamlessly switches chip rules and math logic for all official grade-level variants.
- **Modern Responsive Web GUI**: Dark mode interface with dynamic animations, sound effects, move history, and customizable AI limits.
